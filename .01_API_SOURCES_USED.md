# These APIs were all stated as Free

## How fast they update, and when to change each key
- **How fast checks run:** on your Mac, up to 40 pages a minute across all sources together. Raise it with `LOCAL_STEPS`, up to 200. On Cloudflare, 8 pages every five minutes.
- **Pace:** each source's own cap per minute, set to stay under its rate limit.
- **Key expiry:** written from memory. Check each provider's site to be sure.

**Key changes, in short**
- **Regularly:** SAM.gov every 90 days, and the Threads token every 60 days.
- **Once now:** the FEC and Congress.gov keys, because they were exposed in the old git history. Skip this if you already replaced them.
- **Everything else:** no regular changes, unless a key leaks.

**Delays built into the sources**
- **Campaign money:** most campaigns file quarterly, so new totals appear after each filing deadline. Outside spending near an election is reported within a day or two.
- **Lobbying:** reported quarterly.

Websites read directly, and files imported by hand, are in [.02_WEBSITE_SOURCES_USED.md](.02_WEBSITE_SOURCES_USED.md).

**How they are used (built October 24, 2026):** every source here with a free key or no key that can run alongside the others is now used at the same time; see "What refreshes" in [the README](README.md#what-refreshes). Each item below is marked *(in use)*, *(by hand)* for sources imported with a script, or *(not used)* with the reason. ## **In use before the overhaul**
### Refreshed automatically while the app runs (see API updates in the app)
- **FEC API:** campaign totals (including how much came from individual donors, as a total), PAC contributions and outside spending. Donors' names are never kept; their giving is totaled by employer for the top donor organizations. Needs a free key **(Federal only)**. [api.open.fec.gov/developers](https://api.open.fec.gov/developers/)
    - **Added Nov. 1, 2026:**
        - **Donors by gift size** *(in use, daily)*: each campaign's individual contributions in the FEC's five size groups (`schedules/schedule_a/by_size`), with the campaign totals (`committee/{id}/totals`) to place the unitemized gifts.
        - **PAC types** *(by hand, `npm run pacs:types`)*: each PAC's FEC committee ID from the campaign's processed PAC receipts (`schedules/schedule_a`, line 11C) or the FEC's committee-name search (`names/committees`), then its registration (committee type, designation and sponsor's organization type) from `committees/`, 100 at a time.
        - **Bundled (earmarked) gifts** *(by hand, `npm run funders:bundled`)*: what each conduit PAC (AIPAC, Club for Growth, EMILY's List, J Street, the Senate Conservatives Fund) forwarded to each profiled campaign, from the PAC's disbursements (`schedules/schedule_b`, by recipient committee).
- **Congress.gov API:** bills each member sponsored in the current Congress. Needs a free key **(Federal only)**.
    - Key: [api.congress.gov/sign-up](https://api.congress.gov/sign-up/)
    - Docs: [github.com/LibraryOfCongress/api.congress.gov](https://github.com/LibraryOfCongress/api.congress.gov)

## **Added: floor speeches**
- **Congress.gov Congressional Record endpoints** *(not used: GovInfo splits the Record into speeches with each speaker's ID)*: daily and bound Record, using your existing key **(Federal only)**. [Endpoint docs](https://github.com/LibraryOfCongress/api.congress.gov/blob/main/Documentation/DailyCongressionalRecordEndpoint.md)
- **GovInfo API** *(in use)*: the Congressional Record broken into individual speeches, back to 2016: each new issue speech by speech, and each earlier day once from its metadata file (one request a day). It uses a free api.data.gov key, so your Congress.gov key may work **(Federal only)**.
    - Docs: [api.govinfo.gov/docs](https://api.govinfo.gov/docs)
    - Key: [govinfo.gov/api-signup](https://www.govinfo.gov/api-signup)
- **crec** *(not used: the refresher reads the GovInfo API directly)*: free Python package that turns GovInfo's Record into a table of speeches with dates **(Federal only)**. [crec.readthedocs.io](https://crec.readthedocs.io)
- **YouTube Data API** *(in use)*: videos from officials' own channels (speeches, town halls), with a free Google key and 10,000 units a day. Each channel's uploads list costs 1 unit a request, so the daily check uses a few dozen **(State and federal)**. [Docs](https://developers.google.com/youtube/v3/getting-started)

## **Added: hearings**

## **Added: statements and issue positions**
- **Vote Smart API** *(not used: paid license only)*: candidates' issue positions, votes and interest-group ratings. It isn't free for this project: Vote Smart quoted a Developer license (internal use only: $350 for 1 month, $1,000 for 3 months, $1,900 for 6) and a Public Distribution license, needed once the site shows its data, from $4,850 a year (October 2026). A license also forbids crediting Vote Smart or linking to it on the site, so the Vote Smart card's name and links would have to come off first, and your application said its data won't be used with AI. The refresh code is built but stays off while the key is blank, and the site works without it. Free alternatives: the interest-group scorecards in [.02_WEBSITE_SOURCES_USED.md](.02_WEBSITE_SOURCES_USED.md), and the votes, bills and statements the site already collects **(State and federal)**. [votesmart.org/votesmart-api](https://www.votesmart.org/votesmart-api)
- **Google Fact Check Tools API** *(in use)*: published fact-checks of politicians' claims (PolitiFact, FactCheck.org and others), with a free Google key. Google's page doesn't state the quota **(State and federal)**. [Docs](https://developers.google.com/fact-check-tools)
- **GDELT DOC API** *(in use)*: news coverage search back to 2017, with no key. It sometimes refuses requests briefly, so it needs retries **(State and federal)**. [Announcement](https://blog.gdeltproject.org/gdelt-doc-2-0-api-debuts/)
- **New York Times Article Search API** *(in use)*: the news archive, with a free key, capped at 1,000 results per search **(State and federal)**. [developer.nytimes.com](https://developer.nytimes.com/)
- **Bluesky public API** *(in use)*: officials' public posts, with no login or key. Each person's official and campaign website domains are checked as handles, plus accounts confirmed by `npm run social:bluesky`; congress-legislators lists none **(State and federal)**. [Docs](https://docs.bsky.app/docs/category/http-reference)
- **Threads API keyword search** *(in use once Meta approves access)*: Threads posts filtered to one account and one keyword, free with a Meta app; searching other people's posts needs the `threads_keyword_search` permission approved in App Review, and a user can run 2,200 searches a day **(State and federal)**. [Docs](https://developers.facebook.com/docs/threads/keyword-search)
- **X (Twitter) API** *(ruled out)*: no free tier for new developers since February 2026; reading posts is pay-per-use, about half a cent per post. Facebook and Instagram have no public API for other people's posts, and Meta's Content Library is for approved researchers only.

## **Added: state officials' records**
- **Open States API** *(in use)*: state bills, votes, sponsorships, legislators, committees and governors for all 50 states, DC and Puerto Rico, with a free key **(State only)**.
    - Docs: [v3.openstates.org/docs](https://v3.openstates.org/docs/)
    - Key: [openstates.org/accounts/signup](https://openstates.org/accounts/signup/)

- **LegiScan** *(in use, weekly through its query API, well inside the cap; the bulk files are not used)*: legislation in all 50 states and Congress, with a free key and 10,000 queries a month, resetting on the 1st. ## **Added: stock trades and holdings**
- **CapitolGains** *(by hand, scripts/build-holdings.py)*: free Python package for trades, holdings and blind trusts from both chambers **(Federal only)**. [pypi.org/project/capitolgains](https://pypi.org/project/capitolgains/)
- **Capitol API** *(not used: it reads the same official filings CapitolGains reads)*: open-source and self-hostable **(Federal only)**. Its GitHub repo is crnicholson/capitol-api, and the page I found it on is [an archived copy](https://archive.hackclub.com/archive/8ODyA/mhtml/html).
- **Bargo Congress Trades API** *(in use)*: free with limits; works without a key at a lower limit. Its published OpenAPI description has no late-filing field, so lateness is worked out from the trade and filing dates. The free tier covers only the last 3 months of trades, at 100 requests and 1,000 rows a day with a free key, so older trades need the official filings **(Federal only)**.
    - API: [bargo.ai/free-apis/congress/v1](https://www.bargo.ai/free-apis/congress/v1)
    - Free key: [bargo.ai/free-apis/dash](https://www.bargo.ai/free-apis/dash)
- **Eulerpool** *(optional cross-check; its congress-trading path comes from its product page and is unconfirmed)*: free tier of 100,000 requests a month, with party and committee filters **(Federal only)**.
    - Docs: [eulerpool.com/financial-data-api/congress-trading-data](https://eulerpool.com/financial-data-api/congress-trading-data)
    - Free key: [eulerpool.com/developers/register](https://eulerpool.com/developers/register)
- **Financial Modeling Prep** *(in use when its key is set)*: has a free plan, but check whether it includes congressional trades **(Federal only)**. [Senate trading API docs](https://site.financialmodelingprep.com/developer/docs/senate-trading-api)
- **Disclosed Capitol API** *(not used: paid after a one-time trial)*: members' trades, and the president's and cabinet's, with a free key **(Federal only)**.
    - Cost: a new account gets 750 credits as a one-time trial. After that, calls use a paid plan or pay-as-you-go credits, so it can't be a free daily backup. Don't add a card or start the "Core" trial.
    - Terms: its Terms of Service bar showing its content publicly without written permission, though its dataset's README says the API allows commercial use. Moot while it isn't used.
    - Instead: the president's trades come from its free open dataset, imported by hand (see [.02_WEBSITE_SOURCES_USED.md](.02_WEBSITE_SOURCES_USED.md)).
    - Key: sent in the `DC-API-Key` header. Docs and key: [disclosedcapitol.com/developers](https://www.disclosedcapitol.com/developers) · [Terms](https://www.disclosedcapitol.com/terms)
- **SEC EDGAR** *(in use)*: company tickers and industry codes, with no key (it asks for a contact in each request and about 10 requests a second), to sort trades by sector for the committee-conflict rule **(Federal only)**. [SEC developer resources](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)

## **Don't use (shut down, closing or not free)**
- **Vote Smart API:** paid license only, from $350 a month to build with or $4,850 a year to publish, and the site may not credit Vote Smart. Details above **(State and federal)**.
- **ProPublica Congress API:** no longer available and no new keys **(Federal only)**. [Shutdown notice](https://projects.propublica.org/api-docs/congress-api/)
- **OpenSecrets API:** reported switched off in 2025. Use FEC data directly instead. Its bulk data is unreliable too: users report sign-up requests going unanswered **(Federal only)**. [Forum thread](https://groups.google.com/g/opensecrets-open-data/c/LN8enXEzeDc)
- **Google Civic Information API, representative lookup:** shut down in April 2025 (its elections and divisions parts still work) **(State and federal)**. [Turndown notice](https://groups.google.com/g/google-civicinfo-api/c/9fwFn-dhktA/m/ftUoL83mAwAJ)
- **GovTrack API and bulk data:** ended in 2017 **(Federal only)**. [Notice](https://congressionaldata.org/ending-govtracks-bulk-data-and-api/)
- **House Stock Watcher and Senate Stock Watcher:** reportedly offline *(unconfirmed)* **(Federal only)**.
- **Lambda Finance:** its congressional-trading API shuts down August 31, 2026 **(Federal only)**. [lambdafin.com](https://www.lambdafin.com/congressional-trading-api)
- **Paid only:** Quiver Quantitative (about $25–30 a month), EODHD congressional trades, Ballotpedia, Cicero and BallotReady.
- **PACER:** charges per page; check CourtListener's free archive first **(Federal only)**.
- **Couldn't confirm:** whether Finnhub's congressional trades are on its free plan.
